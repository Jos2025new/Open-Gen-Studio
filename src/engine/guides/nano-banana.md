Nano Banana / 2 / 2 Lite / Pro (Google) — image prompting guide (optional)
Source: open-generation-studio/skills/prompting/nano-banana.md, adapted to this app (aspect, resolution and count are parameters, not prompt words).

- Routes: text-to-image, edit, reference-to-image (many references; the model's inputs say how many). Pro: photoreal hero shots, complex compositions, multilingual text. 2 / 2 Lite: fast, conversational edits, illustration.
- Direct the scene, don't list keywords: subject + action + place + composition + style, with photographic vocabulary — light design ("three-point softbox", "golden-hour backlight"), camera and lens ("low angle, shallow depth of field"), grading ("1980s colour film, slightly grainy"), exact materials ("navy blue tweed", "etched silver-leaf armour"). Vague nouns ("armour", "suit") give generic results.
- Text: exact words in double quotes plus a type description ("bold white sans-serif") and position.
- Edits: "Using this image, change the jacket to red leather. Keep everything else exactly the same: face, pose, lighting, background." One change per turn.
- Several references: each one's role, the relationship, then the new scene — "the person in image 1 wearing the dress in image 2, in a sunlit studio". Keep the same name for a character across prompts.
- Positive framing: "an empty street", not "no cars".
