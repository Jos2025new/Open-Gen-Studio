## Edición de nodos en varios paths seleccionados

El editor de nodos solo tenía una ruta para un path activo. Se añadió una selección de paths explícita y un overlay compartido: Object usa paths elegidos dentro de una capa; Layer usa paths de las capas seleccionadas que sean visibles, desbloqueadas y vectoriales. Marquee y selección de nodos trabajan sobre ese conjunto. El arrastre aplica el mismo desplazamiento en coordenadas de página y lo convierte por separado para cada transformación. Un path sin nodos seleccionados conserva su geometría. No se convierten primitivas, no se unen paths y no se añaden operaciones topológicas ni snapping multi-path; la ruta previa de un solo path permanece.

La regresión unitaria `tests/multi-path-edit.test.ts` verifica targets de Object/Layer, movimiento de paths transformados de forma distinta, preservación de nodos no seleccionados y de un path con selección vacía. Typecheck pasa. El E2E focalizado `tests-e2e/multi-select.spec.ts` pasó 1/1: Object y Layer, marquee, movimiento conjunto, path ajeno intacto, cancelación, y un undo/redo. El fixture del gesto separa una ruta que se solapaba con el hit-target; por tanto no prueba selección con objetivos superpuestos. El E2E comprueba el recorrido React/store/render real, no pruebas manuales ni cobertura de todas las operaciones de nodos.
