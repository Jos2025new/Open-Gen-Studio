# Nodos de herramienta y catálogo de operaciones

`ToolNodeBody` (`nodes.tsx:640`) es el panel del nodo de herramienta. Se muestra debajo del nodo seleccionado (`nodes.tsx:776`). Las operaciones salen de `OPS` (`engine/ops.ts:41`). Los selectores de Nodes ofrecen `OP_IDS` sin las de varias entradas (`engine/ops.ts:482`, `nodes.tsx:654`): es decir, **22 de las 23 operaciones**; solo falta `join_clips`. El comentario de `ops.ts` dice que las operaciones de máscara «se lanzan desde Sketch, no desde menús, nodos ni el agente» (`engine/ops.ts:29`) pero `edit_region` y `remove_object` sí aparecen en los selectores de nodos (el filtro `opsFor`, que las excluye, no se usa aquí); ver [hallazgos](hallazgos.md).

## Cómo se elige el modelo de cada operación

El panel solo enseña el modelo en 4 operaciones de vídeo. Para las demás, el modelo lo decide `requestContext` al revisar y ejecutar (`flow/actions.ts:217`) y **no se muestra ni en el nodo ni en la revisión de gasto** (las líneas de la revisión son `id · título`, `nodes.tsx:66`): ver [hallazgos](hallazgos.md) y [dependencias](dependencias.md).
