# Hallazgos de Nodes

**Criterio del usuario, 2026-10-29 (H1):** cambiar de modelo no es grave por sí mismo. El agente puede escoger uno similar si encaja y no afecta al rendimiento; un modelo más caro necesita aviso y, según el contexto, consulta o aceptación. No debe propagar esos cambios por cascadas de nodos o generaciones. No se ha reproducido un caso ni se decidió una guarda general.

Estados del rastreo ([rastreo de Nodes](../rastreo/nodes.md)): «respondido por lectura» no significa corregido ni que una prueba pendiente pasara; «sin decisión encontrada» no es «olvido». El inventario inicial salió de leer código; cuando hay tests, pantalla o ejecución con proveedor posterior, se identifican por separado en la fila y en [huecos](huecos.md)/[auditoría](../audits/repro-2026-10-29.md). «Gravedad»: promesa rota, entregable equivocado o fricción de uso son críticos; lo que solo exige una decisión del producto va como «decisión». Cada fila dice si el comportamiento se **divulga** al usuario y dónde. Las promesas P1/P2/P3 están en [dependencias](dependencias.md). «Sin confirmar» = el código leído no permite afirmarlo.

## Qué no es hallazgo

- «Results remain in the gallery» al borrar nodos es verdadero (`deleteNodes` solo toca el grafo).
- El estilo Auto del agente solo aprueba ejecuciones de coste exactamente 0; `run_nodes` siempre pide clic.
- La revisión de gasto se revalida por firma antes de ejecutar: si el grafo cambió, no se gasta.
