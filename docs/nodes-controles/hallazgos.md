# Hallazgos de Nodes

Estados del rastreo ([rastreo de Nodes](../rastreo/nodes.md)): «respondido por lectura» no significa corregido ni que una prueba pendiente pasara; «sin decisión encontrada» no es «olvido». Todo sale de leer el código; **nada se ejecutó** (ni app ni navegador). «Gravedad»:  promesa rota, entregable equivocado o fricción de uso son críticos; lo que solo exige una decisión del producto va como «decisión». Cada fila dice si el comportamiento se **divulga** al usuario y dónde. Las promesas P1/P2/P3 están en [dependencias](dependencias.md). «sin confirmar» = el código leído no permite afirmarlo.

## Qué no es hallazgo

- «Results remain in the gallery» al borrar nodos es verdadero (`deleteNodes` solo toca el grafo).
- El estilo Auto del agente solo aprueba ejecuciones de coste exactamente 0; `run_nodes` siempre pide clic.
- La revisión de gasto se revalida por firma antes de ejecutar: si el grafo cambió, no se gasta.
