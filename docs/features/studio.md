# Studio: chat y tablero (pasos 1 a 3)

2026-10-15, `task/gui-cohesion`. Studio es el espacio de trabajo de chat (`ui.workspace = 'chat'`), no un `ui.space`: una sola conversación, con el chat a la izquierda y una columna de tablero a la derecha. No cambia proveedores, lógica de generación, costes ni datos; solo presentación y preferencias de UI.

| Vista Designer del tablero (pasos 3 y 4): el Designer incrustado (`EmbeddedDesigner`): el `Stage` de siempre con una barra superior (menú Archivo, diseño activo, Seleccionar y mover, Mano, deshacer, rehacer, zoom, ajustar) y una barra inferior como la paleta del Designer completo: Línea (lineart), Color, Tamaño, Borrador, Formas (el menú de formas y líneas de `ToolRail`) y Texto, más Capas (ventana con la lista compacta: ojo, capa activa con clic, Mayús/Ctrl para varias, candado; orden solo lectura). Color y Tamaño editan lo que la herramienta activa dibuja, en el mismo estado y campos que el Designer completo (línea: `ui.lineart`; formas: relleno y grosor; texto: color y cuerpo; borrador: solo tamaño; el selector de color es `InlineColor`). Sin reglas, exportar suelto, tamaño de lienzo, importar desde el chat ni la elección de dibujo; sin portal a la barra superior.
