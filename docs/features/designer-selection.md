# Selección en Edit

Edit → Object trabaja con trazos y formas de la capa activa; Edit → Layer trabaja con capas. Son conjuntos distintos, así que Align permanece desactivado en Object si solo hay filas de capas elegidas: cambia a Layer para alinear esas capas. El tooltip de Align explica el cambio.

Arrastrar desde espacio vacío en Edit selecciona según el modo visible: objetos de la capa activa o capas visibles compatibles. En ambas direcciones solo selecciona cajas completamente contenidas; Shift añade y Alt quita, como en la selección raster de OGS. El rectángulo se dibuja en coordenadas de pantalla y sigue el puntero con zoom/desplazamiento. Las pistas flotantes dejan pasar el gesto al lienzo. La selección raster conserva su herramienta y su estado separados. Las capas bloqueadas pueden entrar en la selección, pero sus operaciones siguen protegidas.

En Object, Shift/Ctrl-clic añade o quita objetos de la misma capa; en Layer el modificador hace lo mismo con capas. Un clic simple en un objeto no elegido reemplaza el conjunto y un clic en vacío lo limpia. Clic simple sobre un miembro ya elegido conserva el grupo, igual que Inkscape. Ctrl en OGS es modificador de selección; Inkscape lo usa para seleccionar dentro de grupos, función que OGS no expone aquí. Los conjuntos Object y Layer siguen separados: Object no selecciona elementos de varias capas.

La geometría del marquee está probada en [marquee.test.ts](../../tests/marquee.test.ts); la ruta de clicks/selección preexistente, en [layer-click-replaces.test.ts](../../tests/layer-click-replaces.test.ts). Los E2E [edit-marquee.spec.ts](../../tests-e2e/edit-marquee.spec.ts) y [multi-select.spec.ts](../../tests-e2e/multi-select.spec.ts) ejercitaron selección Object/Layer, reemplazo y limpieza, gesto sobre la pista flotante, Align y movimiento de grupo con undo/redo.

El redondeo compartido reutiliza ese conjunto explícito: en Object permite varios rectángulos de una sola capa; en Layer permite rectángulos de varias capas seleccionadas. No se afirma selección de objetos Object entre capas: ese selector y Align siguen limitados a una capa. El control común muestra Rx/Ry, avisa si sus valores difieren y cambia solo los ejes editados; solo alcanza rectángulos visibles de capas desbloqueadas. Elipses, trazos, capas ocultas o bloqueadas permanecen intactos. El E2E [multi-select.spec.ts](../../tests-e2e/multi-select.spec.ts) comprobó Rx para dos rectángulos Object y Ry para tres rectángulos de dos capas, con un undo/redo que revierte/restaura el grupo.

La edición de nodos admite varios paths explícitos: Object solo dentro de una capa; Layer recorre las capas seleccionadas que estén visibles, desbloqueadas y sean vectoriales. «Edit nodes» abre un overlay compartido, con marquee y selección de nodos en esos paths. Arrastrar un nodo seleccionado mueve el grupo con el mismo delta de página aunque sus transformaciones difieran; un path sin nodos elegidos conserva su geometría. Cancelar el marquee no cambia la selección ni el documento; el movimiento se registra como un único undo/redo. No se convierten primitivas ni se unen paths. Las operaciones topológicas y el ajuste durante el gesto siguen siendo de un solo path.

Los unitarios [multi-path-edit.test.ts](../../tests/multi-path-edit.test.ts) comprueban los targets de ambos modos, transformaciones distintas, nodos no seleccionados y que un path con selección vacía se preserve. El E2E focalizado de [multi-select.spec.ts](../../tests-e2e/multi-select.spec.ts) ejercita Object y Layer: entrada al modo, marquee sobre dos paths, movimiento del grupo, path no seleccionado intacto, cancelación y undo/redo. El fixture tuvo que separar un path que se solapaba con el objetivo del puntero; por ello esta prueba no verifica selección por marquee con hit-targets superpuestos.
